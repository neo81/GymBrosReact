# GymBros 🏋️‍♂️

**GymBros** es tu compañero de entrenamiento inteligente, diseñado para ayudarte a planificar, seguir y analizar tu progreso en el gimnasio de manera sencilla y efectiva.

## ✨ Características Principales

- **Gestión de Rutinas:** Crea y personaliza tus rutinas de entrenamiento por días de la semana.
- **Base de Datos de Ejercicios:** Explora una amplia variedad de ejercicios filtrados por grupos musculares.
- **Seguimiento de Progreso:** Visualiza tu evolución con gráficos detallados de volumen y fuerza.
- **Cronómetro Integrado:** Controla tus tiempos de descanso entre series directamente desde la app.
- **Personalización de Perfil:** Ajusta la experiencia según tus datos físicos y objetivos.
- **Experiencia PWA:** Instalable en tu dispositivo móvil para un acceso rápido y sin distracciones.

## 🛠️ Tecnologías Utilizadas

- **Frontend:** React 18 + TypeScript
- **Estilos:** Tailwind CSS (v4)
- **Animaciones:** Motion (framer-motion)
- **Iconos:** Lucide React
- **Gráficos:** Recharts
- **Build Tool:** Vite

## 🚀 Instalación y Desarrollo

Sigue estos pasos para ejecutar el proyecto localmente:

1. **Clonar el repositorio:**
   ```bash
   git clone <url-del-repositorio>
   cd gymbros
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Ejecutar en modo desarrollo:**
   ```bash
   npm run dev
   ```
   La aplicación estará disponible en `http://localhost:3000`.

4. **Construir para producción:**
   ```bash
   npm run build
   ```

## 📱 Soporte PWA

GymBros está configurado como una **Progressive Web App**. Puedes instalarla en tu pantalla de inicio desde el navegador (Chrome en Android o Safari en iOS) para disfrutar de una experiencia de pantalla completa y mejor rendimiento.
